# Fixture provenance

The Smalls HTML fixtures are trimmed excerpts of official public pages fetched on October 4, 2026. They preserve the schedule selectors and date/clock evidence, omit photographs and scripts, and are used only for parser tests. The free-policy excerpt is from https://www.smallslive.com/livestream/. The positive event is https://www.smallslive.com/events/33909-alexander-mccabe-quartet/. Negative cases are explicitly synthetic mutations in test code. Browser fixtures are synthetic and intercepted only in tests; none are in dist/events.json.
